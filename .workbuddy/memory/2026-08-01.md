## 九九乘法表：阵列/交换可视化空白修复
- 根因：`MatrixViz`/`SwapViz` 用 `grid + aspect-square + 1fr` 列，外层 `mx-auto` 在父级 flex 居中下宽度塌成内容宽度，而 `minmax(0,1fr)` 网格 min-content=0 → 格子宽高算成 0，整片不可见。Group/Add/Line 因有确定尺寸/文字不受影响。
- 修复：改用「显式像素格子尺寸」——`gridTemplateColumns/Rows: repeat(n, Npx)` + 容器确定宽度；cell 随 a/b 缩放（matrix floor(200/max) 限 10–22，swap floor(150/max) 限 8–18）。交换两网格分别按 a×b、b×a 渲染。
- 验证：tsc 0 错、build exit 0、dev server HTTP 200。
